# CleanUpDesk 1.0.0

First public release of CleanUpDesk, an offline Windows file analysis and safe cleanup application.

## Highlights

- Browse local and removable volumes and maintain a local SQLite metadata index.
- Combine filename, extension, size, date, path, type, attribute, and volume filters.
- Analyze duplicates by name, size, or SHA-256, with expandable groups and explicit copy-retention choices.
- Find empty files/folders and the largest 100 eligible files; hide warning items before filling the result limit.
- Preview temporary files, optional supported browser HTTP caches, and the Recycle Bin before cleanup.
- Review deletions in two separate steps. Permanent deletion requires an additional typed phrase; failed recycling never silently becomes permanent deletion.
- Spanish interface, light/dark themes, cancellable work, completion notifications, and safe shutdown of active processes.

## Installation

Download the executable ZIP attached to this release, extract **all** files into a folder, and open `CleanUpDesk.App.exe`. The GitHub-generated "Source code" downloads contain source, not a ready-to-run application.

- `CleanUpDesk-1.0.0-win-x64.zip`: self-contained Windows x64 package, when attached; includes the .NET desktop runtime.
- `CleanUpDesk-1.0.0-win-x64-framework-dependent.zip`: alternative package, when attached; requires .NET Desktop Runtime 10 x64.
- `SHA256SUMS.txt`: checksums for the attached executable packages.

Only download the package actually attached to the release. No installer or digital signature is provided; Windows may display a security warning for an unsigned application.

## Safety and limitations

Windows 10/11 x64 are the target platforms. A complete clean-machine/hardware/accessibility matrix remains manual validation. Indexes can be stale or incomplete after external changes, access denial, or disconnection. Refresh the relevant scope when needed. Age and logical size are estimates, not proof that a file is unused or of exactly reclaimable space. Protected paths are blocked; the application does not elevate privileges.

No accounts, application telemetry, or external services are used. Local indexes contain personal names and paths and are not encrypted. Nothing is automatically deleted on startup. Back up important data before using deletion tools.
